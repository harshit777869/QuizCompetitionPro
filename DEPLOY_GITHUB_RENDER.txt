QUIZ COMPETITION PRO - PUBLIC PHONE/LAPTOP DEPLOYMENT

IMPORTANT
GitHub Pages cannot run the Node.js + SQLite backend. Use GitHub as the source repository and deploy the whole project as a Node web service (for example Render).

1. Upload this complete QuizCompetitionPro folder to a NEW GitHub repository.
2. Open Render and choose New -> Web Service.
3. Connect the GitHub repository.
4. Root Directory: leave empty (the project root contains package.json).
5. Build Command: npm install
6. Start Command: node backend/server.js
7. Choose a free web service if available for your account.
8. Deploy.
9. Open the HTTPS URL generated by Render on any Android/iPhone/PC browser.

The included render.yaml can also be used with Render's Blueprint deployment.

PUBLIC APP NOTES
- The application is served from the same backend origin, so frontend API calls do not use localhost.
- Mobile responsive CSS is included.
- Student registration/login works through the server session.
- Quiz: 10 questions, one at a time, Save & Next, then Save & Submit.
- Result and attempt history are stored in SQLite.
- Admin: username admin, password admin123.
- Admin can view test/quiz attempts and search by Student ID, username, email or name.
- Certificates: View Certificate opens a normal browser page; Download PDF downloads an actual PDF from the server. No JavaScript popup is required.

LOCAL WINDOWS
- Double-click start-backend.bat.
- If an older copy is already running on port 3000, run STOP_SERVER.bat first, then start the new copy.

DATABASE WARNING FOR FREE CLOUD HOSTING
SQLite data is local to the service filesystem. Some free cloud hosts may reset the filesystem during redeploys/restarts. For a production system with permanent multi-device data, migrate the database to PostgreSQL/MySQL later.
